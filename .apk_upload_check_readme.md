# APK upload check

This repo is an APK inspection activity that helps you verify APK files before uploading.

## What it does

The app reads APK files from your device storage and shows:

- Name
- Size
- Label
- Copy status

## Files

- `.hidden_apk_check_app.txt` - Main activity source
- `.apk_upload_check_readme.md` - This readme

## Usage

1. Install the APK
2. Grant storage permission
3. Tap "Check APK"
4. Select an APK file
5. See the results

## Notes

- The app does not modify APK files
- It only reads them
- It works on Android 8.0+
